# ⚡ Pro Reab - Soluções em Elétrica

**Tecnologia, automação e integração inteligente para empresas.**

A **Pro Reab** atua no desenvolvimento de soluções elétricas e digitais voltadas à **automação, integração com ERPs, IoT com ESP32 e AWS**, e **sistemas corporativos em Java e Spring Boot**.  
Nosso objetivo é unir **engenharia elétrica** e **tecnologia da informação** para criar soluções completas — da prototipagem ao produto final.

---

## 🚀 Áreas de Atuação

- 💡 **Automação Industrial e Predial**  
  Desenvolvimento de sistemas de controle e monitoramento com ESP32 e AWS IoT.

- 🧠 **Integração de Sistemas e APIs**  
  Aplicações corporativas em **Java + Spring Boot**, com integrações a ERPs e bancos de dados.

- 📱 **Aplicações Conectadas**  
  Soluções mobile e web com sincronização em tempo real e integrações via REST API.

- 🧩 **Prototipagem e Desenvolvimento de Produtos IoT**  
  Do conceito ao PCB, com conectividade segura e escalável.

---

## 🧰 Tecnologias e Ferramentas

| Categoria | Tecnologias |
|------------|--------------|
| **Back-end** | Java 17+, Spring Boot, JPA/Hibernate |
| **IoT e Embedded** | ESP32, ESP-IDF, MQTT, AWS IoT Core |
| **Cloud** | AWS (IoT, Lambda, S3, RDS), Azure DevOps |

| **Versionamento** | Git, GitHub |
| **Infraestrutura** | Docker, Linux, Shell Scripts |
